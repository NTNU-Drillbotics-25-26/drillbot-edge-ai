The gauge panel displays vertical bar gauges for real-time drilling parameters on the left monitor.

**Default gauges:**
- RPM (rotation speed)
- WOB (weight on bit)
- Top Drive Torque
- Hoisting Torque
- ROP (rate of penetration)

**Optional gauges (can be added):**
- Flow
- Pressure
- WOB Raw

## Adding/Removing Gauges

**To add a gauge:**
1. Right-click anywhere on the gauge panel
2. Select "Add Gauge"
3. Choose the parameter from the list

**To remove a gauge:**
1. Right-click on the gauge you want to remove
2. Select "Remove Gauge"

## Setting Alarm Limits

**To set min/max alarm limits:**
1. Right-click on any gauge
2. Select "Set Alarm Limits"
3. Enter minimum and maximum values
4. Yellow markers appear on the gauge at your limits

**Visual indicators:**
- Yellow horizontal lines show alarm limits
- Gauge bar changes color when limit exceeded
- Alarm triggers in the alarm panel
