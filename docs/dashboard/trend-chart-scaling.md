# Trend Chart Scaling

Individual parameters on the trend chart can be scaled independently for better visibility.

**Note:** You cannot zoom the entire trend chart as a whole. Each parameter must be scaled individually.

**To scale a parameter:**
1. **Select** the trend line or click the legend label for the parameter
2. **Scroll** mouse wheel to zoom the scale in or out
3. **Drag up/down** to shift the scale range (pan)

**Use cases:**
- Make small variations more visible by zooming in
- Compare parameters at different scales
- Focus on specific value ranges

**Tips:**
- If a trend line looks flat, zoom in to see detail
- Reset by scrolling out or selecting a different parameter
- Multiple parameters can have different scales simultaneously

**Example:** If WOB varies between 20-25 kg, zoom the WOB scale to 15-30 kg for better resolution of changes.
