# Setting Parameter Alarms

Parameter alarms alert you when drilling values exceed safe or desired limits.

**To set parameter limit alarms:**
1. **Right-click** any vertical gauge on the left monitor
2. Enter **min** and **max** values for the parameter
3. Click OK to apply

**Visual indicator:**
- Yellow horizontal marker lines appear on the gauge at your limits
- Easy to see at a glance if parameter is within range

**When limits are exceeded:**
- A visible alarm indicator activates
- An alarm sound plays
- The alarm appears in the alarm bar

## Adjusting Existing Alarms

**Method 1 - Right-click:**
1. Right-click the gauge
2. Change the min/max values
3. Click OK

**Method 2 - Drag and drop:**
- Click and drag the yellow horizontal marker directly on the gauge
- Release at the new desired position

**Tip:** Set conservative limits initially and adjust based on actual drilling conditions.
