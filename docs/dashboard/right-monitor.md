The right monitor is the operator's primary screen for trajectory progress and autonomous control.

**Components on the right monitor:**
- **State panel** - Current autonomous state (0-5)
- **Trend charts** - Historical parameter plots
- **3D well progress** - Trajectory visualization with targets
- **Right joystick panel** - Autonomous control buttons

**Primary use:**
- Monitor autonomous drilling state
- View trajectory vs planned path
- Control autonomous operation (start, stop, enable drives)
- Review historical trends

**Key controls (right joystick):**
- Green button: Start Autonomous
- Red button: Disable Drives
- Blue button: Set WOB = 0
- Black button: Enable Drives

**Trajectory display:** Grey curve = planned path, Blue curve = actual path. Compare to verify drilling accuracy.
