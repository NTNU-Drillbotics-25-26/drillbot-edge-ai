The left monitor is the operator's primary screen for drilling parameters and alarms.

**Components on the left monitor:**
- **Alarm bar** - Active alarms displayed at top
- **Message window** - System messages and notifications
- **Azimuth gauge** - Current toolface orientation
- **Vertical gauges** - WOB, RPM, torque, flow, pressure
- **Left joystick panel** - Vibration feedback controls

**Primary use:**
- Monitor drilling parameters (WOB, RPM, torque)
- View and acknowledge alarms
- Control vibration feedback via left joystick

**Important distinction:**
- **WOB** = Measured weight on bit (actual value)
- **WOB setpoint** = Target value for the control system
- These are not the same value; the control system adjusts to match setpoint

**Alarm interaction:** Use the left joystick green button to acknowledge alarms.
