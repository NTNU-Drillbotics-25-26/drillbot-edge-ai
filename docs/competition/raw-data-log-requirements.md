Teams must provide directional survey raw data logs.

Each log entry must include a timestamp with year, month, date, hour, minute, and second.

Each entry must also include sensor measured depth, recorded downhole sensor values, sensor axis values, calculated survey qualifier values, and an accepted survey indicator.

If human secondary qualification is used, both the autonomous and human acceptance indicators must be shown.
