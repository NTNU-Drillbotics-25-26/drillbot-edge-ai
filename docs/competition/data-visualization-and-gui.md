The GUI should present drilling progress and automation state in a way judges can understand quickly.

The display should make it easy to determine bit depth, elapsed time, ROP, MSE, inclination, vibration, and other key calculated or measured variables used to explain rig performance.

All depth values must use the rig floor or drill floor datum.

Poor data presentation or weak GUI usability can reduce scoring.
