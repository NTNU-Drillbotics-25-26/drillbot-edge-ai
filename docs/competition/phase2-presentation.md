Finalist teams must prepare a pre-recorded presentation before the Phase II test.

Judges review the recording and prepare questions for a Q and A session before drilling.

The presentation should summarize the final design, explain important changes from Phase I, highlight major features and lessons learned, and compare actual costs with the original estimate.

Teams are encouraged to involve multiple student presenters so judges can assess shared technical understanding.
