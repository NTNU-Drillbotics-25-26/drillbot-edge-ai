Rules for autonomous operation during the Phase II drilling test.

**Core requirement:** Once drilling starts, the machine must operate autonomously.

**Not allowed:**
- Remote operation
- Remote intervention
- Manual steering control

**Allowed:**
- Manual intervention to add or remove steering mechanism
- Orientation setting must be calculated autonomously
- Setting must be shown on the rig floor display

**Must be autonomous:**
- All directional control operations
- Timing of drilling mode changes
- Length of drilling modes (slide vs rotate)
- Trajectory calculations and steering decisions

**Key principle:** The operator should monitor but not actively control the drilling process.
