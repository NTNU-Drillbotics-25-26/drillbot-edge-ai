The BHA (Bottom Hole Assembly) provides structure, steering capability, and houses the downhole sensor.

**BHA components (top to bottom):**
1. Upper stabilizer - Centralizes the assembly
2. Sensor housing - Contains the Arduino downhole sensor
3. Fixed bent sub - Creates inclination for directional drilling
4. Wear plate - Protects against wear
5. Lower stabilizer - Provides additional stabilization
6. Bit sub - Connects to the drill bit
7. Universal joint - Allows angular movement
8. Internal drive shaft - Transmits torque to the bit

**How steering works:**
- The bent sub has a fixed bend angle
- By rotating the toolface (azimuth), the direction of the bend changes
- This steers the wellbore in the desired direction
- The universal joint allows the bit to follow while the string rotates

**Key principle:** Controlling azimuth orientation controls the drilling direction.
