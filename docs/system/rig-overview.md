The rig is a human-in-the-loop autonomous directional drilling system designed for the Drillbotics competition.

**Key capabilities:**
- Autonomous directional drilling toward target points
- Real-time trajectory tracking and steering
- Manual mode for operator-controlled drilling
- Safety systems with automatic limits

**Operator role:**
- Sets trajectory and target points via GUI
- Chooses manual or autonomous mode
- Monitors the run in real-time
- Can stop the process at any time

**Control modes:**
- **Autonomous:** System follows planned trajectory automatically
- **Manual:** Operator controls drilling directly via joysticks

**The operator remains responsible** for monitoring the run and has full authority to stop operations at any time using the E-stop or Disable Drives button.
