The rig is designed for human-in-the-loop operation, not fully unattended autonomous drilling.

**What human-in-the-loop means:**
- The operator must remain aware of what the automation is doing
- The operator can override or adjust automation at any time
- The operator is responsible for safety decisions

**Operator responsibilities:**
- Monitor drilling parameters and alarms
- Watch trajectory progress
- Be ready to intervene if needed
- Use E-stop or Disable Drives if problems occur

**Override capabilities:**
- Press Disable Drives to stop autonomous operation
- Use joysticks to take manual control
- Adjust setpoints via GUI

**DrillFeel integration:** The operator can use the DrillFeel chair and vibration feedback to maintain situational awareness while the system drills autonomously.

**Note:** The rig should never be left unattended during operation.
